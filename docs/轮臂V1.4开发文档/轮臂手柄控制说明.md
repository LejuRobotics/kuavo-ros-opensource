# 轮臂手柄控制说明

## 概述

本文档说明如何使用手柄控制轮臂机器人，包括三种控制模式及其切换方式。

## 控制模式

系统提供三种控制模式：

1. **cmd_vel 模式**
2. **cmd_vel_world 模式**
3. **躯干控制模式**（手柄摇杆→`/cmd_torso_vel`；复位→`/mobile_manipulator_reset_torso`；SDK 绝对位姿→`/cmd_lb_torso_pose`）

## 模式切换

### 切换按键组合

- **LB + A键（BUTTON_STANCE）**：切换到 `cmd_vel` 模式
- **LB + Y键（BUTTON_WALK）**：切换到 `cmd_vel_world` 模式
- **LB + B键（BUTTON_TROT）**：切换到 `躯干控制`模式

### 默认模式

系统启动时默认模式为 **cmd_vel** 模式。

### 其他功能按键

- **BACK键**：杀掉程序

## 模式详细说明

### 1. cmd_vel 模式 / cmd_vel_world 模式

**话题**：`/cmd_vel` 或 `/cmd_vel_world `

**控制方式**：
- **左摇杆上下方向（X轴）**：控制 `linear.x`（前进/后退线速度）

- **左摇杆左右方向（Y轴）**：控制 `linear.y`（左右移动线速度）

- **右摇杆左右方向（Yaw轴）**：控制 `angular.z`（绕Z轴旋转角速度）

**死区**：0.05（摇杆输入值小于死区时视为0）

---

### 2. 躯干控制模式

**手柄摇杆 → 速度话题**：`/cmd_torso_vel`（`geometry_msgs/Twist`：`linear.x/z`、`angular.y/z` 为瞬时速度）

**复位**：调用服务 `/mobile_manipulator_reset_torso`

**SDK / 其它上层绝对位姿**：`/cmd_lb_torso_pose`（直接写入开环目标，与 vel/delta 不冲突）

**控制方式**：

此模式下需要配合按键使用摇杆进行控制。遥控节点不再在内部维护躯干绝对位姿——摇杆操作转换为瞬时速度，由 RM（ReferenceManager）做 sticky 积分（松开摇杆发零速停止，0.3s 无新消息超时清零）。

#### 躯干X位置控制
- **LB + 左摇杆上下方向**：控制躯干X位置速度
  - **注意**：需要按住LB键才触发控制，松开LB键时速度归零

#### 躯干Z位置控制
- **LB + 右摇杆上下方向**：控制躯干Z位置速度
  - **注意**：需要按住LB键才触发控制，松开LB键时速度归零

#### 躯干Yaw角度控制
- **RB + 右摇杆左右方向**：控制躯干Yaw角速度
  - **注意**：需要按住RB键才触发控制，松开RB键时速度归零

#### 躯干Pitch角度控制
- **RB + 左摇杆上下方向**：控制躯干Pitch角速度
  - **注意**：需要按住RB键才触发控制，松开RB键时速度归零

#### 复位功能
- **RT键**：按下RT键时，调用 `/mobile_manipulator_reset_torso` 将躯干复位到初始位置

**死区**：0.05

**特殊说明**：
- 进入躯干控制模式时，系统会自动切换到MPC的ArmOnly模式
- 退出躯干控制模式时，系统会恢复之前的MPC模式
- **遥控节点无状态**：摇杆→瞬时速度 → RM 做唯一开环积分。软暂停（`/enable_control false`）时 RM 清零粘性速度，解冻后从零开始，无跳变
- **多个躯干话题可共存**：手柄发 `/cmd_torso_vel`；SDK/其它上层可发 `/cmd_lb_torso_pose`，三个话题均作用于同一个开环目标（vel 叠加，绝对位姿直接写入）

---

## 使用提示

1. **模式切换**：使用LB键配合A/Y/B键进行模式切换，切换时会有控制台输出提示
2. **死区处理**：摇杆输入值小于0.05时会被视为0，避免微小抖动
3. **躯干控制**：
   - 在躯干控制模式下，需要按住对应按键才能调整控制值，松开按键后速度归零（躯干保持当前位置）
   - 摇杆→瞬时速度 → RM 做 sticky 积分；0.3s 无新消息自动停
   - 按下RT键可以快速复位所有躯干控制量到初始位置
4. **紧急停止**：按下BACK键可以杀死程序
5. **模式切换**：模式切换前要保证手柄控制量为0，且保持2秒钟，之后才能进行模式切换
