# 轮臂机器人接口文档

> **适用范围**: 轮臂机器人（全向轮底盘 + 双臂 + 躯干 + 头部），关节布局为 4 下肢/腰部 + 14 手臂 + 2 头部。
>
> 通用关节指令话题 `/joint_cmd` 及手臂控制接口 `/kuavo_arm_traj` 等参见《[运动控制API](./运动控制API.md)》。

## 1. 话题 (Topics)

### `/sensors_data_raw`

**类型:** `kuavo_msgs::sensorsData`

**功能说明:**

实物机器人、仿真器发布的传感器原始数据，包含关节状态、IMU、末端执行器和力/力矩传感器数据。

**消息字段:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| header | std_msgs/Header | 标准消息头，包含序列号、时间戳和坐标系 |
| sensor_time | time | 传感器数据的时间戳 |
| joint_data | kuavo_msgs/jointData | 关节数据（位置、速度、加速度、力矩） |
| imu_data | kuavo_msgs/imuData | IMU 数据 |
| end_effector_data | kuavo_msgs/endEffectorData | 末端执行器数据（夹爪等），未配置时为空 |
| FTsensor_data | kuavo_msgs/FTsensorData | 力/力矩传感器数据，未配置时为空 |

**关节数据 (joint_data) 顺序说明:**

其中 `joint_data` 的数组长度为 `NUM_JOINT`, 对应的数据顺序为:

- **前 4 个**为下肢/腰部电机数据（索引 0 ~ 3），顺序为从底盘到躯干:
  - 索引 0: knee_joint (膝关节)
  - 索引 1: leg_joint (腿部关节)
  - 索引 2: waist_pitch_joint (腰部俯仰关节)
  - 索引 3: waist_yaw_joint (腰部偏航关节)
- **接着 14 个**为手臂电机数据:
  - 索引 4 ~ 10: 左臂电机数据（`l_arm_pitch`, `l_arm_roll`, `l_arm_yaw`, `l_forearm_pitch`, `l_hand_yaw`, `l_hand_pitch`, `l_hand_roll`）或（`zarm_l1_link` ~ `zarm_l7_link`）
  - 索引 11 ~ 17: 右臂电机数据（`r_arm_pitch`, `r_arm_roll`, `r_arm_yaw`, `r_forearm_pitch`, `r_hand_yaw`, `r_hand_pitch`, `r_hand_roll`）或（`zarm_r1_link` ~ `zarm_r7_link`）
- **最后 2 个**为头部电机数据（索引 18 ~ 19），分别为 `head_yaw` 和 `head_pitch`

**单位说明:**

- 关节位置: radian（弧度）
- 关节速度: radian/s
- 关节加速度: radian/s²
- 关节力矩 (`joint_torque`): N·m（注意：该字段存储的是关节扭矩值，非电流值；实际电流需根据电机参数换算）

**IMU 数据 (imu_data):**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| gyro | geometry_msgs/Vector3 | 陀螺仪角速度，单位 rad/s |
| acc | geometry_msgs/Vector3 | 加速度计加速度，单位 m/s² |
| free_acc | geometry_msgs/Vector3 | 无重力加速度数据，单位 m/s² |
| quat | geometry_msgs/Quaternion | IMU 的姿态（四元数） |

### `/odom`

**类型:** `nav_msgs::Odometry`

**功能说明:**

用于发布小车的里程计信息，包含位置、姿态和速度。

**使用说明:**

- 由底盘里程计节点发布
- WBC 控制器从中读取 `pose.pose.position`（x, y）、`pose.pose.orientation`（yaw 角）和 `twist.twist`（线速度 x/y、角速度 z）

---

### `/cmd_vel`

**类型:** `geometry_msgs::Twist`

**功能说明:**

底盘速度控制指令，用于控制机器人小车的目标速度，包含 xy 方向线速度和 yaw 方向角速度。

**消息字段:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| linear.x | float64 | x 方向线速度，单位 m/s |
| linear.y | float64 | y 方向线速度，单位 m/s |
| linear.z | float64 | 未使用 |
| angular.z | float64 | yaw 方向角速度，单位 radian/s |
| angular.x | float64 | 未使用 |
| angular.y | float64 | 未使用 |

**使用说明:**

- 该话题由外部运动规划模块发布，`ControlDataManager` 订阅后传递给 WBC 控制器
- 控制器内部经过梯形加减速限制后，通过 `/move_base/base_cmd_vel` 发送给底盘驱动
- 可通过 `/enable_vel_control` 服务开启/关闭速度控制，状态通过 `/enable_vel_control_state` 话题（latched）发布

---

### `/joint_cmd`

**类型:** `kuavo_msgs::jointCmd`

**功能说明:**

WBC 控制器输出的最终关节控制指令，直接下发给硬件驱动执行。包含全部关节（下肢/腰部 + 手臂 + 头部）的目标位置、速度、力矩等控制参数。

**用途:** 通常由 WBC 控制器以高频（约 500Hz）发布，一般无需外部用户直接操作。

**消息字段:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| header | std_msgs/Header | 标准消息头，包含时间戳 |
| joint_q | float64[] | 目标关节位置数组，单位: radian |
| joint_v | float64[] | 目标关节速度数组，单位: radian/s |
| tau | float64[] | 目标关节力矩数组，单位: N·m |
| tau_max | float64[] | 关节最大力矩限制数组，单位: N·m |
| tau_ratio | float64[] | 力矩比例系数数组 |
| joint_kp | float64[] | 关节比例增益数组 |
| joint_kd | float64[] | 关节微分增益数组 |
| control_modes | int32[] | 控制模式数组，0: 力矩控制（Torque），1: 速度控制（Velocity），2: 位置控制（Position） |

**数组索引说明:**

| 索引范围 | 关节部位 | 数量 |
| --- | --- | --- |
| 0 ~ 3 | 下肢/腰部关节（knee, leg, waist_pitch, waist_yaw） | 4 |
| 4 ~ 17 | 手臂关节（4~10 左臂, 11~17 右臂） | 14 |
| 18 ~ 19 | 头部关节（head_yaw, head_pitch） | 2 |

---

### `/enable_control_state`

**类型:** `std_msgs::Bool`

**功能说明:**

WBC enable/disable 状态话题（latched）。WBC 发布，`ControlDataManager` 与 `ReferenceManager` 订阅同步。

- `True` = 正常受控
- `False` = 暂停所有动作控制（冻结到当前规划状态）

---

### `/enable_vel_control_state`

**类型:** `std_msgs::Bool`

**功能说明:**

速度控制开关状态话题（latched）。由 WBC 控制器发布，指示当前是否启用底盘速度控制。

- `True` = 启用速度控制，底盘按 `/cmd_vel` 指令运动
- `False` = 禁用速度控制，底盘保持静止

## 2. 服务 (Services)

### `/lb_leg_control_srv`

**类型:** `kuavo_msgs::lbLegControlSrv`

**功能说明:**

腿部/腰部关节控制服务，用于直接控制机器人的腿部/腰部关节角度。

**注意:** 该服务会启动一个控制循环来执行关节控制，如果控制循环已经在运行，则会更新目标关节角度。

**请求参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| target_joints | float64[4] | 目标关节角度数组，包含 4 个关节的角度值，单位: radian |
| duration | float64 | 运动持续时间，单位: 秒（s） |

**响应参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| success | bool | 控制是否成功，True 表示成功，False 表示失败 |

**target_joints 数组说明:**

| 索引 | 关节名称 | 描述 |
| --- | --- | --- |
| 0 | knee_joint | 膝关节 |
| 1 | leg_joint | 腿部关节 |
| 2 | waist_pitch_joint | 腰部俯仰关节 |
| 3 | waist_yaw_joint | 腰部偏航关节 |

**使用说明:**

- **警告:** 请确保传入的关节角度在安全范围内，避免机器人出现异常姿态
- `duration` 参数决定了关节从当前位置运动到目标位置的时间，合理设置可避免运动过快

### `/lb_optimization_ik_service`

**类型:** `kuavo_msgs::lbBaseLinkPoseCmdSrv`

**功能说明:**

轮臂腿部逆运动学服务，根据目标 `base_link` 位姿计算所需的腿部/腰部关节角度。

**功能:** 提供轮臂系统的运动学求解，支持带底盘信息的 IK 计算。

**用途:** 用于运动规划、姿态控制和轨迹跟踪等高级控制功能。

**请求参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| with_chassis | bool | 是否包含底盘信息进行计算 |
| control_type | int8 | 控制类型: 0 = 底盘优先，1 = 腰部优先 |
| chassis_info | float64[3] | 底盘信息 `[x, y, yaw]`，单位: 米和弧度 |
| q_lb | float64[4] | 当前腿部/腰部关节角度 `[knee, leg, waist_pitch, waist_yaw]`，单位: radian |
| base_link | float64[7] | 目标 base_link 位姿 `[x, y, z, qw, qx, qy, qz]`，位置单位: 米，姿态为四元数 |

**响应参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| success | bool | IK 求解是否成功，True 表示成功，False 表示失败 |
| lb_leg | float64[4] | 计算得到的腿部/腰部关节角度 `[knee, leg, waist_pitch, waist_yaw]`，单位: radian |
| time_cost | float64 | IK 计算耗时，单位: 毫秒 (ms) |

**算法特点:**

- 支持带底盘约束的运动学求解
- 考虑关节限位和碰撞约束
- 提供求解时间反馈用于性能监控
- 支持参考位置优化求解结果

**使用示例:**

```python
from kuavo_msgs.srv import lbBaseLinkPoseCmdSrv, lbBaseLinkPoseCmdSrvRequest

ik_service = rospy.ServiceProxy('/lb_optimization_ik_service', lbBaseLinkPoseCmdSrv)

# 创建请求
request = lbBaseLinkPoseCmdSrvRequest()
request.with_chassis = True
request.control_type = 0  # 0: 底盘优先, 1: 腰部优先
request.chassis_info = [0.0, 0.0, 0.0]  # 底盘位置和朝向
request.q_lb = [0.21, -0.375, 0.0202, 0.0]  # 当前关节角度
request.base_link = [0.227, -0.017, 1.019, 0.807, 0.019, -0.025, -0.589]  # 目标位姿

# 调用服务
response = ik_service(request)
if response.success:
    print(f"IK求解成功，关节角度: {response.lb_leg}")
    print(f"计算耗时: {response.time_cost} ms")
```

### `/enable_control`

**类型:** `std_srvs::SetBool`

**功能说明:**

暂停/恢复轮臂 WBC 层所有动作控制。仅限 WBC 层。

**行为:** 暂停时冻结到当前 tick 的规划状态（软急停），恢复前所有控制指令被丢弃。

**请求参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| data | bool | `True` = 恢复控制；`False` = 冻结到当前规划状态，丢弃后续指令 |

**响应参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| success | bool | 调用是否成功 |
| message | string | 状态描述信息 |

**冻结策略（disable 期间）:**

| 部位 | 冻结来源 |
| --- | --- |
| 底盘（x, y, yaw） | 当前观测值 |
| 腰部/下肢（4 关节） | 当前规划值 |
| 手臂（14 关节） | 当前规划值 |
| 头部（2 关节） | 最后一条有效命令目标 |

**使用示例:**

```python
import rospy
from std_srvs.srv import SetBool, SetBoolRequest

rospy.wait_for_service('/enable_control')
enable_srv = rospy.ServiceProxy('/enable_control', SetBool)

# 暂停
resp = enable_srv(SetBoolRequest(data=False))
print(resp.message)

# 恢复
resp = enable_srv(SetBoolRequest(data=True))
print(resp.message)
```

| --- | --- | --- |
| success | bool | 调用是否成功 |

### `/change_arm_ctrl_mode`

**类型:** `kuavo_msgs::changeArmCtrlMode`

**功能说明:**

切换手臂控制模式。支持三种模式，切换时会经过 200ms 的保持阶段和平滑插值过渡，避免运动跳变。

**请求参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| control_mode | int32 | 控制模式（见下方说明） |

**响应参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| result | bool | 是否切换成功 |
| mode | int32 | 切换后的控制模式 |
| message | string | 状态描述信息 |

**控制模式:**

| 值 | 名称 | 说明 |
| --- | --- | --- |
| 0 | keep_pose | 保持当前位置，不做主动控制 |
| 1 | auto_swing_arm | 行走时自动摆臂，切换到该模式会自动运动到预设的摆手姿态 |
| 2 | external_control | 外部控制，手臂的运动由外部指令控制（通过 `/kuavo_arm_traj` 等话题） |

**使用说明:**

- 模式 0 → 模式 2 切换时，会先用当前关节状态初始化外部控制目标，避免跳变
- 模式 2 需要配合 `/kuavo_arm_traj` 或 `/humanoid_mpc_target_arm` 话题使用，参见《[运动控制API](./运动控制API.md)》

### `/enable_lb_arm_quick_mode`

**类型:** `kuavo_msgs::changeLbQuickModeSrv`

**功能说明:**

轮臂 MPC 快慢模式切换。在 MPC 的 ArmOnly 或 BaseArm 模式下，可直接旁路 MPC，让手臂或下肢跟踪外部下发的最新指令，实现更快的响应。

**请求参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| quickMode | int8 | 快模式选择（见下方说明） |

**响应参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| success | bool | 是否切换成功 |
| message | string | 状态描述信息 |

**quickMode 取值:**

| 值 | 说明 |
| --- | --- |
| 0 | 关闭快模式（正常 MPC 控制） |
| 1 | 下肢快模式：下肢直接跟踪外部指令 |
| 2 | 上肢快模式：手臂直接跟踪 `/kuavo_arm_traj` 外部指令 |
| 3 | 全快模式：上下肢同时跟踪外部指令 |

**使用说明:**

- 仅在 MPC 控制模式为 ArmOnly（mode=1）或 BaseArm（mode=3）时生效
- 快模式下关节指令不经 MPC 优化，直接透传，适用于需要快速响应的场景

### `/change_lb_mpc_obs_update_mode`

**类型:** `kuavo_msgs::changeLbMpcObsUpdateModeSrv`

**请求参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| obsUpdateMode | int8 | 反馈模式（见下方说明） |

**响应参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| success | bool | 是否切换成功 |
| message | string | 状态描述信息 |

**obsUpdateMode 取值:**

| 值 | 说明 |
| --- | --- |
| 0 | 全部反馈：所有关节使用传感器实测值作为 MPC 反馈 |
| 1 | 屏蔽下肢反馈：下肢关节使用 MPC 输出期望值替代传感器反馈 |
| 2 | 屏蔽上肢反馈：手臂关节使用 MPC 输出期望值替代传感器反馈 |
| 3 | 全屏蔽：上下肢关节均使用 MPC 输出期望值替代传感器反馈 |

### `/set_contact_force_params`

**类型:** `kuavo_msgs::setContactForceInterpParams`

**功能说明:**

设置手臂末端接触力的插值参数，控制期望力从当前值过渡到目标值的速度和过渡时间。

**请求参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| transition_time | float64 | 过渡时间，单位: 秒（s），必须 > 0 |
| interpolation_speed | float64 | 插值速度，必须 > 0 |

**响应参数:**

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| success | bool | 调用是否成功 |
| message | string | 状态描述信息 |

**使用说明:**

- 该服务用于调整双臂接触力控制（如推、拉、按等操作）的动态响应特性
- `transition_time` 决定期望力从 0 到目标值的总过渡时间
- `interpolation_speed` 决定每控制周期的插值步长
