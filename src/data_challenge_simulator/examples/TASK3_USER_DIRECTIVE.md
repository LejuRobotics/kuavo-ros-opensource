## 动作流程

### 1. 初始化后的单次手掌指令

- 初始化完成后，命令手掌到达物体上方，并让手掌平行桌面。
- 这是一次性的只命令动作，不做是否达到的检测，也不要求保证达到。
- 该指令不得成为后续流程的约束，不得污染后面的动作或判断。

### 2. 第一次 IK

- 第一次 IK 的目标是让手到达物体上方。
- 该目标的 Z 高度没有用户指定的固定值，可由实现选择。

### 3. 手姿态变化与下降

- 手到达物体上方后，先改变手部姿态。
- 随后下降合适距离。
- 下降结束时，在已经完成姿态变化的前提下，指尖应有一部分位于物体中空内部。
- 从这一阶段开始，不再要求手掌平行桌面；“手掌平行桌面”只属于初始化后的那一次指令。

### 4. 张开、单指锁存与物体锁存

- 张开夹取不使用物理冲量，只使用简单的接触逻辑判断。
- 手指张开并接触内壁后，执行逻辑判断并锁存该整根手指。
- 某根手指锁存后，不应再向该手指发送张开指令。
- 接触锁存的顺序是：手指张开、接触内壁、逻辑判断并锁存。
- 不允许先通过物理接触获得冲量，再进行锁存。
- 三根手指中任意两根完成锁存后，判定物体锁存。
- 物体锁存后，物体跟随手移动。

### 5. 搬运与释放

- 物体锁存后，通过 IK 抬起手和物体。
- 随后机器人整体移动到左边桌子处。
- 最后释放物体。
