## 人确定的目标

上升阶段只有一个任务目标：左右 `hand_base` 最终达到已经在
`task2_grasp_pose_demo.py --lift-waypoint 8` 中确认的双手姿态。

这里的“姿态”是完整位姿，不只是手掌角度：

- 左 `hand_base`：三维位置和三维方向；
- 右 `hand_base`：三维位置和三维方向。

目标以“抓取时箱体坐标系”表示，而不是以 `base_link`、世界坐标系、
两手中点或运行时人工构造的双手坐标系表示。这样两个相同箱子以及小范围
停靠误差可以共用同一组目标。

当前目标保留已确认离线终态的 `x/y` 和方向，并按 2026-09-15
运行反馈将左右终点改为比抓取点净上移约 `0.020 m`，以避免抬升过高：

## 坐标转换

规划时读取选中箱在抓取前的实测世界位姿：

```text
T_world_box_at_grasp
```

将配置中的左右目标转换到世界系：

```text
T_world_left_target  = T_world_box_at_grasp * T_box_left_target
T_world_right_target = T_world_box_at_grasp * T_box_right_target
```

`base_link` 只通过机器人正运动学影响“某组关节能否到达世界目标”，不参与目标
姿态定义。箱体锁存和跟随也不参与 IK 目标计算。

## 终点 IK

设左右臂 14 个关节组成：

```text
q = [q_left(7), q_right(7)]
```

一次耦合 IK 同时求两只手。终点等式为：

```text
position(FK_left(q_left))   = position(T_world_left_target)
orientation(FK_left(q_left)) = orientation(T_world_left_target)

position(FK_right(q_right))   = position(T_world_right_target)
orientation(FK_right(q_right)) = orientation(T_world_right_target)
```

每只手为三维位置加三维方向，两只手合计 12 维。这里的 12 维就是已确认
双手终态本身，不是额外的过程约束。

14 个关节满足 12 维终态后仍有冗余。当前只用以下目标选择一个关节解：

```text
minimize ||q - q_contact||^2
```

它只在满足同一双手终态的解之间选择离抓取关节最近的解，不放宽或改变终态。
关节上下界来自当前 MuJoCo 模型。求解器为 SLSQP，终点位置和方向作为硬等式。

当前 IK 数值验收只检查求解本身：

- 最大手掌位置残差不超过 `1e-5 m`；
- 最大手掌方向残差不超过 `1e-4 rad`；
- 求解器必须报告成功。

这些是 IK 解是否满足目标的数值条件，不是初始化门限、动作跳过条件或 fallback。

## 明确删除的旧约束

当前上升终点 IK 不再使用：

- 保持规划接触点的左右手方向；
- 保持规划接触点的两手位置差或手心间距；
- 两手中点向世界 `+Z` 上升的软代价；
- 相邻 IK 路点关节变化代价；
- 锁定 `j5`、`j6`、`j7` 或任何单独关节；
- `base_link` 姿态约束；
- 碰撞、接触或箱体跟随作为 IK 目标。

## 路径执行

当前只求一次终点 IK。`lift_waypoint_count=9` 不表示求 9 次 IK：它只是把
`q_contact` 到终点解 `q_target` 做等距关节空间采样，供离线显示和现有轨迹
发布接口使用：

```text
q_i = q_contact + i / 8 * (q_target - q_contact),  i = 0..8
```

这些中间点没有末端方向、手心间距、中点位置或单关节锁定约束。是否需要对
中间路径另做安全设计，必须基于正式运行证据单独决定，不能偷偷写进终点 IK。

## 当前验证结果

离线验证覆盖：

- `box_1` 的标准停靠位姿；
- `box_2` 的标准停靠位姿；
- seed 1 中曾实测的近似停靠位姿 `(0.098, 0.097, 0)`；
- 独立姿态工具的 waypoint 0 和 waypoint 8。

终点结果：

- 两手位置残差约 `1e-15` 到 `1e-14 m`；
- 两手方向残差约 `1e-13` 到 `1e-12 deg`；
- waypoint 8 的左右方向变化显示为 `0.000000 deg`；
- 固定指连线仍约为左 `-179.93 deg`、右 `+179.93 deg`；
- 从抓取关节到确认终态，两手中点实际变化约为
  `[+0.014804, 0, +0.080659] m`。这是确认终态产生的位移，不再把原软目标
  `+0.10 m` 当作最终必须达到的位移。
