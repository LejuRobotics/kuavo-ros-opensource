## 操作

首次双前扳机超过 0.5 后允许等待反馈和初始化就绪；左右可先后按下。请求受理后，即使后续等待超时，也使用 X+A 重试。被拒绝的请求和互斥锁竞争不消耗首次入口。持续捏住板机不会重复提交请求。

Quest 裸手操作：X+A → 等待全身复位完成 → 放下手柄 → 双手持续比 OK → 等待新会话跟随。50 帧按实际有效输入频率计数；不能把手柄遗留的 running 状态当作 OK。回到手柄时也需结束旧跟随并通过 X+A 重新捕获，不能在活动会话中直接替换来源。
