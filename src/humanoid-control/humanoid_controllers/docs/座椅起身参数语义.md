# 座椅流程参数与函数语义（Kuavo5）

> 配置源：`kuavo_assets/config/seat_config_v5.json`  
> ROS 话题/服务名保持不变（如 `/bot_seat_return_preupdate`），仅内部命名自描述化。

---

## 1. 落座序列（sit_down 单次触发）

| 内部阶段 | 含义 | 主要配置 | 主要代码 |
|---------|------|---------|---------|
| 落座 MPC | 站姿 → `sit_joint_pos` | `sit_down_duration_seconds` | `SitReferenceManager` |
| 落座终点冻结 | MPC 暂停、锁参考 | — | `SitControlManager::FROZEN` |
| 关节偏置 | sit → sit+offset，WBC 插值后 CSP 锁定 | `seat_offset_*` | `SitControlManager` P3 |
| 收脚（可选） | 三步腿关节 CSP 插值 | `seat_leg_action_*` | `SitControlManager` P4 |
| 待命 CSP 锁定 | 等待 stand_up | — | `isSitSequenceComplete()` |

## 2. 起立序列（stand_up / use_sit_init）

### 2.1 配置 `stand_up_from_seat`

| 字段 | 含义 |
|------|------|
| `sit_to_stand_com_velocity_mps` | sit→stand 质心竖直速度 (m/s)，use_sit_init 与座椅 stand_up 共用 |
| `hold_at_sit_pose_before_stand_up_seconds` | 反向偏置完成后、开始 sit→stand 前保持 sit 姿态的时间 |
| `mpc_init_delay_after_stand_up_seconds` | sit→stand 结束后、init MPC 前等待 |
| `contact_protect_grace_after_stand_up_seconds` | 起立接触保护：`robotStandUpCompleteTime_` 后额外容忍时间 |
| `head_down_pitch_rad` | 座椅期 `zhead_2` 低头角（rad，正=低头） |
| `head_raise_duration_seconds` | MPC 坐下低头与进 MPC 站立抬头的共用插值时长（秒）；0=瞬间到位 |

反向 settle：
- **实机**：`hardware/seat_return_reverse_prep` → `jointMoveToPrepGoal`（与 use_sit_init phase2a/2b 同路径）
- **仿真**：控制器 CSP 复刻同一套速度键与时间律（cosine `(1-cos(πt))/2`，单段最短 **0.5s**）
- `reverse_leg_before_arm=true`：0a 腿/腰用 `move_speed_deg_per_s`；若启用 arm_clear 则 0b 臂→clear、0c 臂→sit（均 `settle_speed`）；否则 0b 臂→sit
- `false`：全身一次回 sit，用 `settle_speed_deg_per_s`（不可与非零 arm_clear 同开）
- **arm_clear 语义**：`arm_clear = 臂段起点实测臂角 + reverse_arm_clear_joint_offset_rad`（相对 hold，易拧）
P3 正向偏置仍用 `seat_offset_duration_seconds`。

### 2.2 配置 `hardware_sit_pose_prep`（use_sit_init 实机 + 座椅 stand_up 段0）

| 字段 | 含义 |
|------|------|
| `move_speed_deg_per_s` | reverse 时腿/腰回 sit（0a / HW phase2a）；use_sit_init phase1 也用此键 |
| `settle_speed_deg_per_s` | reverse 时臂回 sit（0b / HW phase2b）；无 reverse 时全身回 sit |
| `reverse_leg_before_arm` | 回 sit 是否先腿/腰、后臂（硬件 phase2 与座椅段0 共用） |
| `reverse_arm_clear_joint_offset_rad` | 臂回 sit 前绕扶手中间点：**相对臂段起点实测臂角**的增量 (rad×14)，非绝对角、非相对 sit；全 0=不启用；须 `reverse_leg_before_arm=true` |
| `leg_joint_kp` / `leg_joint_kd` | prep 与 CSP 锁定期间腿 EC 刚度 |

### 2.3 preUpdate 阶段枚举 `StandUpFromSeatStage`

| 值 | 名称 | 轨迹 |
|----|------|------|
| 0 | `ReverseSeatSettle` | 实测 → `sit_joint_pos`（可选 0a 腿腰 / 0b 臂，linear CSP） |
| 1 | `SitToStand` | `sit_joint_pos` → 站立站姿 |

`ReverseSeatSettle` 结束后可进入 `hold_at_sit_pose_before_stand_up_seconds` 保持；
默认再等 start（`/hardware/is_ready=1`）才切 `SitToStand`。

### 2.3.1 配置 `seat_return`

| 字段 | 含义 |
|------|------|
| `await_start_after_p5` | 段0 回 sit 后是否等 start 再段1（对齐 use_sit_init 按 o），默认 true；进入等待时固定清 `is_ready=0` 并置 `ready_to_start=1` |

start 触发方式：终端键盘 `o`、或 `rosservice call /humanoid_controller/real_initial_start`（仿真由 HC 提供；实机由 hardware_node 提供，已同步写 `is_ready=1`）。

### 2.4 关键函数

| 函数 | 语义 |
|------|------|
| `SitControlManager::publishSeatReturnReversePrepParams` | 实机段0：经 `publishHardwarePrepPlan(reverse_only)` 写 `/hardware_prep_*` |
| `SitControlManager::fillSeatCspHoldCmd` | 按 `SeatJointTargets` 填 CSP `jointCmd`（桥接 / sit hold / 仿真段0 共用） |
| `SitControlManager::makeLegFirstMidTargets` | 中间态：腿/腰=sit，臂=实测（仿真段0） |
| `SitControlManager::lerpJointTargets` | 段0 CSP 关节插值（时间律由 `jointMoveToCosine01` 给出） |
| `SitControlManager::jointMoveToCosine01` | 对齐 HW `calcCos` 的归一化时间律 |
| `SitControlManager::maxAbsDq` | 段0 时长：腿腰/臂 `|dq|` 最大值 |
| `SitControlManager::releaseSeatHoldForStandUp` | 释放落座资源，MPC 仍暂停 |
| `humanoidController::beginStandUpFromSeat` | 门禁 + 规划/发 prep + 释放 + 进入 preUpdate |
| `humanoidController::tickAwaitStandUpStart` | 段0 后等 `/hardware/is_ready`（实机/仿真共用） |
| `humanoidController::preUpdate` 段0 | 实机 HW reverse；仿真 CSP 0a/0b → 等 start |
| `humanoidController::preUpdate` 段1 | `standUpWbc` sit→stand |

### 2.5 关键成员（humanoidController）

| 成员 | 语义 |
|------|------|
| `stand_up_from_seat_active_` | 正在执行座椅 stand_up preUpdate |
| `reverse_seat_offset_done_` | 段0 是否完成且已通过 start 门闩 |
| `awaiting_stand_up_start_` | 段0 已完成，正在等 `/hardware/is_ready` |
| `reverse_seat_settle_stage_` | 仿真段0 子阶段：0=0a，1=0b |
| `reverse_seat_offset_start_time_sec_` | 仿真当前子阶段插值起始时刻 |
| `stand_up_from_seat_start_snapshot_` | measured / mid / sit 目标与 0a/0b 时长 |
| `hw_seat_reverse_state_` | 实机段0：`Idle/Handoff/Running/Done/Failed` |
