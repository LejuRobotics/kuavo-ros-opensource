# 座椅流程参数与函数语义（Kuavo5）

> 配置源：`kuavo_assets/config/seat_config_v5.json`  
> ROS 话题/服务名保持不变（如 `/bot_seat_return_preupdate`），仅内部命名自描述化。

---

## 1. 落座序列（sit_down 单次触发）

| 内部阶段 | 含义 | 主要配置 | 主要代码 |
|---------|------|---------|---------|
| 落座 MPC | 站姿 → `sit_joint_pos` | `sit_down_duration_seconds` | `SitReferenceManager` |
| 落座终点冻结 | MPC 暂停、锁参考 | — | `SitControlManager::FROZEN` |
| 关节偏置 | sit → sit+offset，WBC 插值后 CSP 锁定 | `seat_offset_*` | `SitControlManager` P3 |
| 收脚（可选） | 三步腿关节 CSP 插值 | `seat_leg_action_*` | `SitControlManager` P4 |
| 待命 CSP 锁定 | 等待 stand_up | — | `isSitSequenceComplete()` |

## 2. 起立序列（stand_up / use_sit_init）

### 2.1 配置 `stand_up_from_seat`

| 字段 | 含义 |
|------|------|
| `sit_to_stand_com_velocity_mps` | sit→stand 质心竖直速度 (m/s)，use_sit_init 与座椅 stand_up 共用 |
| `hold_at_sit_pose_before_stand_up_seconds` | 反向偏置完成后、开始 sit→stand 前保持 sit 姿态的时间 |
| `mpc_init_delay_after_stand_up_seconds` | sit→stand 轨迹结束后、init MPC 前的稳定等待 |
| `contact_protect_grace_after_stand_up_seconds` | 起立接触保护：`robotStandUpCompleteTime_` 后额外容忍时间 |

反向偏置插值时长 **不单独配置**，复用 `seat_offset_duration_seconds`。

### 2.2 配置 `hardware_sit_pose_prep`（仅 use_sit_init 实机）

| 字段 | 含义 |
|------|------|
| `move_speed_deg_per_s` | 硬件 prep 第一段：移动到 sit+offset 的速度 |
| `settle_speed_deg_per_s` | 硬件 prep 第二段：回到纯 sit 的速度 |
| `reverse_leg_before_arm` | prep 第二段是否先腿/腰、后臂 |
| `leg_joint_kp` / `leg_joint_kd` | prep 与 CSP 锁定期间腿 EC 刚度 |

### 2.3 preUpdate 阶段枚举 `StandUpFromSeatStage`

| 值 | 名称 | 轨迹 |
|----|------|------|
| 0 | `ReverseSeatOffset` | CSP 锁定姿(sit+offset) → `sit_joint_pos` |
| 1 | `SitToStand` | `sit_joint_pos` → 站立站姿 |

`ReverseSeatOffset` 结束后可进入 `hold_at_sit_pose_before_stand_up_seconds` 保持，再切 `SitToStand`。

### 2.4 关键函数

| 函数 | 语义 |
|------|------|
| `SitControlManager::captureStandUpFromSeatStartSnapshot` | stand_up 前快照 CSP 锁定姿关节目标 |
| `SitControlManager::releaseSeatHoldForStandUp` | 释放落座资源，MPC 仍暂停 |
| `humanoidController::beginStandUpFromSeat` | 上述两步 + 进入 preUpdate 起立 |
| `humanoidController::computeReverseSeatOffsetStandUpTarget` | 反向偏置 WBC 目标（blend 0→1） |

### 2.5 关键成员（humanoidController）

| 成员 | 语义 |
|------|------|
| `stand_up_from_seat_active_` | 正在执行座椅 stand_up preUpdate |
| `stand_up_from_seat_stage_` | 当前阶段（ReverseSeatOffset / SitToStand） |
| `reverse_seat_offset_start_time_sec_` | 反向偏置插值起始时刻 |
| `stand_up_from_seat_start_snapshot_` | CSP 锁定姿快照（含 `csp_hold_joint_targets`） |
