# Kuavo5 座椅起身使用指南

> 适用：Kuavo5 机器人。本文档面向使用手柄/按键或上位机指令操作机器人的人员，说明「坐—待命—起」整套流程怎么用。不需要懂代码。

---

## 一、能做什么

机器人可以反复地「坐下 → 待命 → 起身 → 行走 → 再坐下」，循环往复。整个过程只需要三个操作：

| 操作 | 一句话说明 |
|------|-----------|
| **坐下** | 机器人从站立坐到座椅上，自动调整到位后保持不动（待命） |
| **起身** | 机器人从座椅上站起来，站好后就能正常行走 |
| **关机** | 让机器人断电停机（不再保持姿态） |

---

## 二、三个操作怎么用

### 1. 首次开机 + 起身

- **自动完成**：开机时机器人已配置坐姿启动（`use_sit_init`），会自己完成「上电 → 移到准备位 → 起身到站立」全流程，**不需要人干预**。
- **怎么算成功**：机器人站稳、进入待命行走状态（stance）。
- **信号**：`/bot_stand_up_complete = 1` 表示起身成功。

### 2. 运行中坐下

- **前提**：机器人正站立（stance 状态）。
- **操作**：发一次坐下指令（`humanoid/sit_down`）即可。
- **特点**：**只发一次**。机器人会自动完成完整的坐下动作（落座 + 调整姿态），中间不需要再按键。
- **怎么算完成**：机器人坐稳、保持不动。
  - 简单判断：`/bot_sit_down_complete = 1` 表示落座完成。
  - 准确判断：`/seat_sit_sequence_complete = true` 表示整个坐下流程全部完成、进入待命态。
- **完成后**：机器人停在座椅上待命，等待下一次「起身」或「关机」。

### 3. 坐姿起身

- **前提**：机器人已坐稳待命（`/seat_sit_sequence_complete = true`）。
- **操作**：发一次起身指令（`humanoid/stand_up`）即可。
- **注意**：**不需要重新启动程序**。直接发指令，机器人会从坐姿自动站起来。
- **怎么算成功**：机器人站稳、进入待命行走状态（stance）。
- **信号**：`/bot_stand_up_complete = 1` 表示起身成功。
- **完成后**：可以正常推摇杆行走，或再次坐下。

### 4. 关机

- **任意时刻可执行**。
- **操作**：发关机指令（`/stop_robot = true`）。
- **效果**：机器人断电停机，不再保持任何姿态。**不可与坐下/起身混用**——关机后需重新开机走流程 1。

## 四、状态判断速查

用上位机/手柄程序判断机器人状态，只需看这几个信号：

| 想知道 | 看哪个信号 | 满足条件 |
|--------|-----------|---------|
| 起身成功了吗 | `/bot_stand_up_complete` | `= 1` |
| 坐下完成了吗 | `/seat_sit_sequence_complete` | `= true` |
| 现在能不能起身 | `/seat_sit_sequence_complete` | `= true`（才能发 stand_up） |
| 现在在哪个阶段 | `/seat_control_phase` | 1=站 2=落座冻结 3=姿态调整 4=收脚 |

> 坐下过程中 `/seat_control_phase` 会自动从 1 变到 2、3（、4），**不需要人干预**，只是给你看的。

## 五、常见问题

**Q：坐下要按几次？**
A：一次。发一次 `sit_down`，机器人自动完成全部坐下动作到坐稳。

**Q：起身要重启程序吗？**
A：不要。直接发 `stand_up`，机器人会从坐姿自己站起来。

**Q：坐稳待命时再按坐下会怎样？**
A：机器人保持不动，不会关机。要起来就按起身，要停机就发关机。

**Q：起身或坐下中途能打断吗？**
A：不能。运动中再发指令会被拒绝，等当前动作完成后再发。

**Q：能反复坐起多少次？**
A：设计上无限制。每次完成后状态会自动复位，下一次和第一次一样。

---

## 六、一句话总结

- **坐下**：`sit_down`，一次到位，看 `/seat_sit_sequence_complete`。
- **起身**：`stand_up`，不用重启，看 `/bot_stand_up_complete`。
- **关机**：`/stop_robot`，随时可停。
