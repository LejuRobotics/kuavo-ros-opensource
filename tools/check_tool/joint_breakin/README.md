# EC_Master_Tools

一个基于 EC_Master 的 EtherCAT 驱动器调试工具，支持机器人腿部磨线测试功能，适用于不同型号机器人的关节磨合。

## 🎯 项目简介

- 支持多种机器人型号的腿部磨线测试
- 自动检测机器人版本并选择对应的磨线脚本
- 支持Roban2、Kuavo4、Kuavo5等不同机器人平台

## 🤖 支持的机器人平台

| 版本号 | 机器人类型 | EC从站数量 | 磨线脚本 |
|--------|------------|------------|----------|
| 13-14 | Roban2 | 13个 | `roban2_leg_breakin.py` |
| 40-49 | Kuavo4 | 14个 | `kuavo4_leg_breakin.py` |
| 50-51 | Kuavo5 | 15个 | `kuavo5_leg_breakin.py` |

## 🚀 安装与使用

### 自动编译功能

程序具有自动编译功能，无需手动编译：

- 当检测到缺少 `ec_master_wrap.so` 文件时，程序会自动执行编译
- 编译过程可能需要数十秒时间，请耐心等待
- 编译完成后会自动生成所需的Python扩展模块

### 手动编译（可选）

如果需要手动编译：

```bash
mkdir build && cd build    # 创建并进入build文件夹
cmake ..
make
```

> 💡 提示：通常不需要手动编译，程序会在首次运行时自动处理。

## ⚙️ 配置说明

### 环境变量配置

- ROBOT_VERSION：指定机器人型号（13-14为Roban2，40-49为Kuavo4，50-51为Kuavo5）
- 驱动器类型：配置文件 `~/.config/lejuconfig/EcMasterType.ini` 可指定驱动器类型

### 磨线脚本配置

- 脚本会根据ROBOT_VERSION自动选择对应的磨线脚本
- 支持手动选择机器人版本（当环境变量未设置时）

### 启动程序

```bash
sudo su
python3 joint_breakin.py
```

> 💡 提示：首次运行时，如果检测到缺少编译文件，程序会自动进行编译，请耐心等待编译完成。

### 主菜单功能

| 选项 | 功能 | 说明 |
|:----:|------|------|
| 1 | 仅启动手臂磨线 | 包含零点设置，使用RUIWO电机控制 |
| 2 | 仅启动腿部磨线 | 零点位置开始，使用EC_Master电机控制 |
| 3 | 同时启动手臂和腿部磨线 | 包含零点设置，两个程序并行运行 |
| 4 | 退出程序 | 退出磨线程序 |

### 机器人版本检测

程序会自动检测ROBOT_VERSION环境变量：
- 如果检测到版本13-14：自动选择Roban2磨线脚本
- 如果检测到版本40-49：自动选择Kuavo4磨线脚本  
- 如果检测到版本50-51：自动选择Kuavo5磨线脚本
- 如果未检测到：提供手动选择选项

## 🔧 磨线测试流程

### 准备工作
1. 将机器人吊起，确保无干涉
2. 将手臂和腿部摆到零点位置
3. 确保周围无障碍物

### 执行步骤
1. 运行程序：`sudo python3 kuavo_joint_breakin.py`
2. 等待自动编译完成（首次运行时）
3. 选择磨线模式（仅手臂/仅腿部/同时运行）
4. 输入磨线运行时长（最少15秒）
5. 等待程序自动执行磨线动作
